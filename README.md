## 🧹 Servicios Ofrecidos

Limpieza profesional de casas y departamentos:
- **Limpieza Regular** (mantenimiento periódico)
- **Limpieza Profunda** (deep clean exhaustivo)
- **Limpieza de Mudanza** (Move-In / Move-Out)

### Áreas y Tareas Incluidas:
- **Cocinas**: superficies, tarjas, electrodomésticos exteriores/interiores según paquete.
- **Baños**: desinfección total, regaderas, azulejos, inodoros y cancelería.
- **Desempolvado (Polvo)**: muebles, molduras, repisas, marcos.
- **Aspirado y Pisos**: aspirado detallado de alfombras/tapetes, trapeado y desinfección de pisos duros.
